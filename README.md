# Excel 데이터 다운로드 프로젝트

## 소개
이 프로젝트는 Next.js를 사용하여 만든 웹 애플리케이션으로, 데이터를 Excel 형식으로 다운로드할 수 있는 기능을 제공합니다.

## 주요 기능
- Excel 데이터 다운로드
- 더미 데이터 API 제공
- 반응형 웹 디자인

## 기술 스택
- Next.js
- TypeScript
- API Routes
- Excel.js
